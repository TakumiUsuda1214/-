スマートフォン向けの「大学情報アクセス・学習支援アプリ」のUIプロトタイプを作成してください。

このアプリの目的は、大学内に分散している情報を一つにまとめ、学生が必要な情報へ素早くアクセスできるようにすることです。
単なるリンク集ではなく、課題管理、予定確認、大学からのお知らせ、休講情報、Moodle課題連携風UI、食堂メニュー、学生証QRコード、クラブ・サークル情報、AIによる案内機能、多言語対応を含めた、学生生活を総合的に支援するスマホアプリとして設計してください。

PC向けWebサイトではなく、まずはスマホアプリを前提にしたUIにしてください。
iPhoneやAndroidの縦長画面で使いやすい、モバイルファーストのデザインにしてください。
画面幅は390px前後のスマートフォンを基準にしてください。

アプリ名は仮で「大学生活サポートアプリ」としてください。
特定のブランド名やサービス名は強調しなくて構いません。
大学公式アプリのように、信頼感があり、学生が毎日使いやすい雰囲気にしてください。

--------------------------------------------------
全体のデザイン方針
--------------------------------------------------

- スマホアプリ風の画面
- シンプルで見やすい
- 学生向けで親しみやすい
- 白を基調にする
- 紺色と青緑をアクセントカラーにする
- 朝日大学の公式サイトに近い、落ち着いた青系の雰囲気を参考にする
- メインカラーは深い青
- アクセントに青緑や淡い水色を使う
- 派手すぎず、少しおしゃれで質素なデザイン
- 角丸カードを多く使う
- 余白をしっかり取る
- 文字は読みやすく大きめにする
- アイコンを使って直感的に理解できるようにする
- 重要な情報はホーム画面上部に配置する
- 画面遷移数を少なくし、目的の画面に最短で到達できる構成にする
- 学生が迷わず次の行動を選べるUIにする
- 日本人学生と留学生の両方が使いやすい設計にする
- 片手操作しやすい配置にする
- 重要なボタンは親指が届きやすい位置に置く
- カードは縦スクロールで見やすく並べる
- 横スクロールのチップやショートカットを適度に使う
- 1画面に情報を詰め込みすぎない
- 影は薄め
- 角丸はやや大きめ
- 背景は白または薄いグレー
- 危険、重要、未提出、休講などは色で分かるようにする
- 日本語でも英語でもレイアウトが崩れにくいようにする
- アクセシビリティを意識して、十分なコントラストを確保する

- メモ機能の入口

3. AI相談画面
--------------------------------------------------

AI相談画面は、学生が大学生活で迷ったときに質問できるチャット画面にしてください。

チャット形式のUIを作成してください。

入れる内容：

- ユーザーのメッセージ
- 入力欄
- 送信ボタン
- 質問例チップ
- 回答内の関連リンクカード
- 多言語対応を感じられる表示

AI相談で扱う質問例：
- 「履修登録はどこ？」
- 「証明書はどこで発行する？」
- 「Moodleを開きたい」
- 「Moodleの課題を確認したい」
- 「図書館を使いたい」
- 「就職支援を受けたい」
- 「健康相談はどこ？」
- 「今日の食堂メニューは？」
- 「休講情報を見たい」
- 「学生証QRを表示したい」
- 「クラブ活動を探したい」
- “Where can I check my assignments?”
- “Show my Moodle assignments”
- “How can I contact the career center?”
- “Where is the library?”
- “What is today’s cafeteria menu?”
- “Are there any canceled classes today?”

AIの回答例：
- 短い説明
- 関連するリンクカード
- 次にする行動ボタン

例1：
質問：「図書館を使いたい」
回答：
「図書館の蔵書検索や開館情報はこちらから確認できます。」
リンクカード：
- 図書館
- 開くボタン

例2：
質問：「Moodleの課題を確認したい」
回答：
「Moodleから取得した直近の課題を表示します。未提出の課題が2件あります。」
カード：
- 情報リテラシー 第5回レポート
- Academic English Vocabulary Quiz
- Moodleで開くボタン

例3：
質問：「今日の食堂メニューは？」
回答：
「今日のおすすめは日替わり定食とカレーライスです。現在の混雑状況はやや混雑です。」
カード：
- 食堂メニューを見る
- 混雑状況を見る

AI相談画面のデザイン：
- 吹き出し形式
- AI側は淡い青背景
- ユーザー側は濃い青背景
- 入力欄は画面下部に固定
- 質問例は横スクロールできるチップ形式
- 回答は長すぎず、次の行動が分かるようにする
- 関連リンクカードは角丸で見やすく表示

実際のAI API接続は不要です。
プロトタイプとして、あらかじめ用意された質問例や回答が表示される形で構いません。

- メニュー画面に「休講・補講情報」項目を追加
- 通知機能にも休講情報を含める

休講情報カードに入れる内容：
- 授業名
- 担当教員
- 日付
- 時限
- 変更内容
  - 休講
  - 補講
  - 教室変更
  - オンライン授業に変更
- 理由または備考
- 確認済みにするボタン

表示例：
- 「情報リテラシー：本日3限 休講」
- 「Academic English：教室変更 A棟203 → B棟301」
- 「経営学入門：補講日程 6月12日 5限」

UI条件：
- 休講は赤またはオレンジ系のラベルで目立たせる
- 教室変更は青系ラベル
- 補講は青緑系ラベル
- ホームでは重要なものだけを表示
- 詳細画面では一覧として確認できるようにする
- 学生が見逃さないよう、通知バッジや重要ラベルを付ける

インタラクション：
- 休講情報カードをタップすると詳細を表示
- 「確認済み」ボタンを押すと既読・確認済み状態に変わる
- フィルターで「すべて」「休講」「補講」「教室変更」を切り替えられるようにする

12. 操作・インタラクション
--------------------------------------------------

- 言語切り替えメニューを開く
- 選択言語を切り替える
- 通知一覧を開く
- 通知を既読にする
- 休講情報を確認済みにする
- 課題フィルターを切り替える
- カレンダー表示とリスト表示を切り替える
- Moodle同期ボタンを押すと同期中、同期完了の状態を表示
- 課題カードをタップすると課題詳細を表示
- Moodleで開くボタンを表示
- AI相談で質問例をタップすると回答が表示される
- AI相談で送信ボタンを押すとメッセージが追加される
- 回答内の関連リンクカードを表示
- リンクカテゴリを切り替える
- リンク検索ができるように見せる

実際のバックエンド接続は不要です。
デモ用の静的データで構いません。
ただし、ユーザーがタップしたときに反応があり、アプリとして動いているように見えることを重視してください。

--------------------------------------------------
13. UIの細かい条件
--------------------------------------------------

- スマホ幅を想定する
- 画面サイズは390px前後のスマホ幅を基準にする
- 片手で操作しやすい配置にする
- カードは縦スクロールで見やすく並べる
- 横スクロールのチップやショートカットを使う
- 1画面に情報を詰め込みすぎない
- 余白をしっかり取る
- 影は薄め
- 角丸はやや大きめ
- 背景は白または薄いグレー
- アクセントカラーは紺色と青緑
- 重要、未提出、休講、締切間近などは色で分かるようにする
- 文字サイズは小さくしすぎない
- 日本語でも英語でも崩れにくいレイアウトにする
- ボタンやカードにはホバー、タップ、アクティブ状態を用意する
- ローディングや同期中などの状態表現を入れる
- アクセシビリティを意識して、コントラストを確保する
- アイコンはシンプルで統一感のあるものにする
